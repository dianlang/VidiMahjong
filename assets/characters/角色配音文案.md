# 雀夜六人角色配音脚本（服装／配饰阶段变化；所有角色均为成年人）

阶段 0 为初始形象，不播放阶段变化语音。阶段 1~4 依次递进，表现越来越不好意思；没有裸露内容。

- stage-2.mp3：别盯着看啦，我自己会整理的！
- stage-3.mp3：尾巴都不知道往哪儿放了……真是的。
- stage-4.mp3：好、好啦！先让我整理一下衣服嘛……

## character-02 · 小妖精（成年）

- stage-4.mp3：对不起……我现在真的有点慌张。
